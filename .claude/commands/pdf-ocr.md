## 引数

$ARGUMENTS

## タスク

指定した PDF ファイルをテキスト化し、Markdown に変換します。
デジタルPDF（テキスト層あり）とスキャン済みPDFの両方に対応しています。

### 1. ファイル指定確認

```bash
# ファイルパスが指定されているか確認
```

指定されていない場合、ユーザーにファイルパスを尋ねる。

### 2. PDFのタイプを確認

ユーザーに以下を聞く：

**「このPDFはデジタルPDFですか、スキャン済みPDFですか？」**

- **デジタルPDF**: Word / InDesign 等で作成。テキスト層あり。軽量・高速（推奨）
- **スキャン済みPDF**: 紙をスキャン。OCR処理が必要。初回起動時は SmolVLM をダウンロード

### 3. スクリプト実行

```bash
.claude/skills/pdf-ocr/run.sh "<ファイルパス>" "<タイプ>"
```

| タイプ | 説明 |
|-------|------|
| `digital` | デジタルPDF（ローカルモード） |
| `scan` | スキャン済みPDF（ハイブリッドモード） |

### 4. 出力確認

スクリプトが完了したら：

- **成功**: Markdown が stdout に表示され、同一ディレクトリに `.md` ファイルが保存される
- **失敗**: エラーメッセージを表示

### 5. 完了報告

```
✅ PDF を Markdown に変換完了
ファイル: <basename>.md
行数: <行数>
```
