# ccusage - Claude API 使用量確認スキル

Claude Code のトークン消費量と関連コストを追跡・分析するスキルです。自然言語質問に対応しています。

## 機能

- **自然言語質問対応** - 「今月どれくらい使った？」のような日本語質問に対応
- **日次レポート** - 日ごとの使用量集計
- **月次サマリ** - 月単位の支出集計
- **セッション分析** - 個別会話のコスト表示
- **5時間課金ウィンドウ** - Claude の課金サイクルに合わせた追跡
- **キャッシュトークン監視** - キャッシュ作成 / キャッシュ読み込みの分離表示
- **JSON エクスポート** - 他システムとの連携用エクスポート
- **マルチプロジェクト対応** - プロジェクト別の追跡と絞り込み

## 使用方法（自然言語質問）

```
/ccusage 今月どれくらい使った？         # 今月の使用量
/ccusage 昨月の使用量は？              # 先月の使用量
/ccusage 今日の支出は？                # 今日の使用量
/ccusage セッション別の詳細は？        # セッション分析
/ccusage 全体の合計は？                # 合計使用量
/ccusage キャッシュの情報は？          # キャッシュ情報
/ccusage help                         # ヘルプ表示
```

## 使用方法（従来のコマンド）

```bash
/ccusage daily                # 日次レポート
/ccusage monthly              # 月次サマリ
/ccusage sessions             # セッションベースの分析
/ccusage json                 # JSON 形式でエクスポート
```

## 自然言語対応キーワード

### 期間指定
- **今月**: 「今月」「このかず」「今月度」「月の使用量」「月間」
- **先月**: 「先月」「前月」「昨月」
- **今日**: 「今日」「本日」「きょう」
- **昨日**: 「昨日」「きのう」
- **先週**: 「先週」（7日前からの使用量）
- **今週**: 「今週」（日曜からの使用量）
- **先週日曜～今日**: 「先週日曜から今日まで」「先週の日曜から」
- **今週日曜～今日**: 「今週日曜から」
- **相対指定**: 「3日前」「1週間前」など
- **日次**: 「日次」「毎日」「日別」「日ごと」

### 分析対象
- **セッション**: 「セッション」「会話」「conversation」「session」
- **合計**: 「合計」「トータル」「全体」「総」「total」
- **キャッシュ**: 「キャッシュ」「cache」
- **JSON**: 「json」「データ」「詳細」

## 出力形式

- **テーブル形式** - ターミナル幅に自動適応
- **JSON 形式** - API 連携向け
- **テキスト形式** - ロギング向け

## データソース

ローカルの JSONL ファイルからオフラインで処理。キャッシュされた料金データを使用。

## 備考

- オフライン動作対応（インターネット接続不要）
- タイムゾーンとロケールのカスタマイズ可能
- バンドルサイズが小さく、`npx ccusage@latest` で直接実行可能
- 自然言語質問は Python スクリプトで処理
