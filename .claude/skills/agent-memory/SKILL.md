# Agent Memory Skill

Claude Code内での作業内容、調査結果、方針決定などを記憶し、後で検索・復帰できるスキルです。

## 使い方

### 記憶する
「これを記憶して：」や「覚えておいて：」といった発話で内容をマークダウンファイルに保存します。

**例：**
```
このリポジトリのURL構造の仕様を記憶して：
- /docs/path → 静的HTML表示
- /api/docs/path → JSONレスポンス
- RAW表示は ?raw=true パラメータで切り替え
```

### 検索・復帰する
「○○について思い出して」や「以前の○○を検索して」と言うと、記憶から関連内容を検索します。

**例：**
```
URL ルーティングについて思い出して
```

## 記憶ファイルの形式

フロントマターに `summary` を含むマークダウン形式：

```markdown
---
title: 記憶のタイトル
summary: 検索時に表示される概要（1-2行）
date: 2026-04-05
tags: [タグ1, タグ2]
---

詳細な内容...
```

## 保存先

- リポジトリ内：`.claude/skills/agent-memory/memories/`
- .gitignore で除外（プライベート領域）
- リポジトリごとに独立した記憶領域

## 仕組み

ファイルベースの実装により：
- ripgrep での効率的な検索
- フロントマターの summary で段階的開示（概要確認→詳細閲覧）
- ポータビリティと操作性を実現
